  \vspace{0.35cm}
  \tituloSeccion{Cómo funciona}
  \vspace{1.1cm}
  \paso{01}{Consulta las ofertas}{n8n programa una búsqueda diaria en LinkedIn mediante Apify y normaliza los datos de cada vacante.}
  \vspace{1.45cm}
  \paso{02}{Revisa dónde se puede postular}{Si hay evidencia para Colombia, la oferta sigue al correo. Las restricciones a otros países se excluyen. Los casos ambiguos quedan para revisión manual.}
  \vspace{1.45cm}
  \paso{03}{Prepara el resumen}{Gmail envía hasta cinco vacantes con el cargo, la empresa, la ubicación y el enlace al anuncio, una vez configuradas las credenciales.}
